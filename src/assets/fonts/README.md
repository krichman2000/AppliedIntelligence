Static TTF builds of the site's Google Fonts, used by the Open Graph image
routes (`opengraph-image.tsx` / `twitter-image.tsx`). Satori, which renders
those images, needs raw font files and cannot use `next/font`.

- Libre Baskerville (Regular 400, Bold 700)
- DM Sans (Regular 400, Medium 500)

Both are licensed under the SIL Open Font License 1.1.
